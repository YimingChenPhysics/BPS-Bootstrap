# BPS-Bootstrap

This is a Github repository accompanying the paper "BPS Bootstrap".

It contains a toy solver (bps-bootstrap-toy-solver-0.8.0.zip) using which one can specify a supercharge Q and explore the properties of its associated BPS states in the large N limit. It is created using Codex.

To use the solver, one should download the zip file to their own computer and simply ask their agent to start it up. 

The repository also contains a pdf file containing the derivation of the bound on \mathcal{D}_\phi claimed in the paper.
